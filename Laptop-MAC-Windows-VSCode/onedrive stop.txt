The important one is Code Helper (Plugin). VS Code uses this process to run its extensions/plugins and their supporting Node.js processes. Microsoft has documented multiple cases where a VS Code extension can cause Code Helper (Plugin) to consume excessive CPU.
https://github.com/microsoft/vscode/issues/296681

Why this is particularly relevant in your case

Your screenshot also shows:

Parent Process: Code (4608)
Process Group: Code (4608)

So this is definitely associated with Visual Studio Code.

The process itself isn't necessarily the problem. An extension running inside VS Code is a likely cause. For example, recent reports have implicated extensions such as Cline, Codex, Pylance, JSON language support, and others in high CPU situations.

First thing I would do

In VS Code:

Command Palette → Developer: Show Running Extensions

This will show which extensions are actually running and how much time they are consuming.

Then, as a quick test:

Command Palette → Developer: Restart Extension Host

If CPU immediately drops and later climbs again, that strongly points toward an extension.

Even better — identify the exact extension

Quit VS Code completely:

⌘ + Q

Then open Terminal and run:

ps aux | grep "Code Helper (Plugin)"

You may see something like:

Code Helper (Plugin) ... ~/.vscode/extensions/xxxxx/...

The path after .vscode/extensions/ will tell us exactly which extension is responsible.

For example, if you see:

~/.vscode/extensions/openai.chatgpt-...

then the OpenAI/Codex extension is involved.

If you see:

~/.vscode/extensions/...

with another extension name, that's the one we investigate.

One important point

Don't start deleting Code Helper (Plugin) itself. It's part of VS Code. The goal is to identify the extension/process running under it.

Given that you're on a 16 GB Mac, having two Code Helper processes around 97% CPU each can absolutely make the machine feel hot, slow, and memory-constrained. There are also recent reports of persistent high CPU from VS Code extension hosts on Apple Silicon Macs.
